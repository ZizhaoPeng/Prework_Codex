# Prework_Codex

[English](README.md) | [简体中文](README.zh-CN.md)

Prework_Codex 是一个面向 Codex 的模型无关型 skill，用于把“已经分析过，但尚未完成”的代码任务整理成可验证、可继续的执行现场。它解决的不是如何写出更长的计划，而是如何让后续代理接手时保留真正影响执行的上下文，避免重新阅读同一批文件、重新搜索调用链、重新验证已经排除的方案。

在任务移交前，主代理需要进入真实代码库，记录关键证据与未决风险，完成并验证第一处有意义的修改，再冻结包含工作范围、写入所有权和验收命令的执行契约。后续代理从这个已经与代码发生过实际接触的状态继续，而不是只拿到一份脱离现场的计划文档。

## 核心机制

- **先接触现实，再进行移交**：主代理必须先检查相关代码、测试和调用关系，并完成一处可逆且经过验证的锚点修改。
- **保留推理所依赖的现场证据**：明确记录已查看的文件、命令结果、已排除路线、暂定判断、风险和剩余待办。
- **冻结执行边界**：每个工作包都包含负责人、允许写入范围、依赖关系、验证命令和成功条件；并行 worker 不得共享可写路径。
- **结果以证据为准**：worker 返回不可覆盖的执行回执，包含实际命令输出、变更路径、产物哈希、偏离项和残余风险。
- **执行与裁决分离**：最终审阅者必须独立重跑必要检查，核对契约、作用域、回执覆盖和集成结果，不能直接采信 worker 的成功声明。

## 适用场景

本工具适合大型或执行量较高的代码任务，尤其是需要由主代理完成关键判断，再交给一个或多个执行代理继续实现的场景。它也适用于长任务中断续跑、并行工作包隔离、可审计的模型切换，以及需要防止多个代理覆盖同一目录或证据文件的工作流。

对于简单单步修改、无法有效拆分的任务，直接执行通常更合适。架构取舍、含糊需求、安全决策、跨工作包冲突和最终发布裁决仍应由主代理或指定审阅者负责。

## 安装

安装器只使用 Python 标准库。默认安装到 `$CODEX_HOME/skills`；未设置 `$CODEX_HOME` 时使用 `~/.codex/skills`：

```bash
python3 install_skill.py --codex-home ~/.codex
```

也可以指定完整目标目录：

```bash
python3 install_skill.py --destination /tmp/codex/skills/prepare-execution-handoff
```

目标已存在时，安装器默认拒绝覆盖。显式传入 `--force` 后会先在同级目录完成暂存，再整体替换旧版本。安装器还会拒绝源目录与目标目录互相嵌套、包含符号链接的 skill 包，以及通过目标路径中的符号链接写入。

## 在 Codex 中使用

安装后，可以直接向 Codex 输入：

```text
使用 $prepare-execution-handoff，在把这个实现任务交给执行代理前建立一个经过验证、可继续的工作现场。
```

典型流程如下：

1. 检查代码库，记录基线、证据、排除路线和风险。
2. 建立带有成功条件、写入范围和验证命令的工作队列。
3. 由主代理完成第一处有效修改，并运行真实验证命令。
4. 冻结执行契约，为各 worker 生成边界明确的任务简报。
5. worker 在独占范围内继续执行，并生成追加式回执。
6. 独立审阅者复核哈希、范围和集成结果，重新运行验收命令后给出最终裁决。

内部 skill 标识保留为 `$prepare-execution-handoff`，以维持现有安装、自动化脚本和调用提示词的兼容性。

## 验证

仓库测试覆盖完整生命周期以及伪造命令结果、锚点变化、路径穿越、越权写入、产物篡改、自我审阅、证据覆盖、不完整回执、共享输入失效、不安全替换和符号链接安装等对抗性场景：

```bash
python3 -m unittest discover -s tests -v
```

## 项目结构

```text
skills/prepare-execution-handoff/
├── SKILL.md                    # Codex 工作流与触发说明
├── agents/openai.yaml          # Codex UI 元数据
├── references/relay-contract.md # 状态、回执与审阅契约
└── scripts/relay_state.py      # 无第三方依赖的状态与校验工具
```

`install_skill.py` 提供安全安装与更新；`tests/` 保存生命周期和安全边界测试。
